## 🚀 Featured Projects

### 📅 [Booking Service API](https://github.com/IyinoluwaGideon/Booking-Service-G)

A backend appointment-management system designed to help businesses manage users, staff members, services and customer bookings.

**Key features:**

* User and administrator registration
* Login and OTP verification
* JWT-based authentication
* Role and permission-based authorization
* Service creation and management
* Staff-to-service assignment
* Appointment booking and rescheduling
* Operating-hour validation
* Prevention of duplicate appointments
* Daily user and staff booking limits
* Appointment-completion confirmation
* Email, reminder and Redis-supported services

**Technologies:** PHP, Mezzio, Laminas, Doctrine ORM, JWT, Redis, Swoole and PHPUnit.

---

### 📚 [Library Management System](https://github.com/IyinoluwaGideon/Library-Management-System)

A RESTful library-management API built with Laravel. It manages books, users, inventory, borrowing and book returns.

**Key features:**

* User registration and login
* Token-based authentication with Laravel Sanctum
* User-management endpoints
* Book creation, retrieval, updating and deletion
* Book inventory management
* Book borrowing and returning
* Borrowing-history retrieval
* Protected API endpoints
* Administrator-restricted operations
* Eloquent models and database relationships

**Technologies:** PHP, Laravel 12, Laravel Sanctum, Eloquent ORM, SQL and REST APIs.

---

### 🏛️ [Library MVC](https://github.com/IyinoluwaGideon/Library-MVC)

A library application developed with core PHP to demonstrate how the Model–View–Controller architecture works without relying on a full PHP framework.

**Key concepts demonstrated:**

* Custom MVC architecture
* Application routing
* Database connection and query handling
* Controllers, models and views
* Object-Oriented Programming
* PSR-4 autoloading
* Composer dependency management
* Separation of application responsibilities

**Technologies:** PHP, SQL, Composer, MVC and PSR-4 autoloading.

---

### 📝 [Simply Appointments API Specification](https://github.com/IyinoluwaGideon/simply-appointments-spec)

A forked OpenAPI specification for an appointment-management platform. The specification documents API contracts for authentication, users, appointments, staff members, services and roles.

**Concepts covered:**

* OpenAPI 3
* RESTful endpoint design
* Request and response schemas
* Bearer authentication
* Reusable API components
* HTTP response codes
* API documentation
